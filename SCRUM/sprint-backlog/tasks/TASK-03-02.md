# TASK-03-02: Endpoints REST para catálogo de publicaciones y control de tarifas

## 1. Descripción Técnica
Construir endpoints: `GET /api/products` (catálogo público/operativo para distribuidores) y endpoints administrativos `POST /api/products` y `PUT /api/products/:id` (restringidos exclusivamente al Administrador para modificar precios y comisiones).

## 2. Historia de Usuario Vinculada
- **Historia Padre:** [[HU-03]]
- **Dependencias Técnicas (Bloqueado por):** [[TASK-03-01]] (DDL products), [[TASK-01-04]] (Middleware RBAC)
- **Componente de Arquitectura:** Backend
- **Estimación:** 4 horas-hombre

## 3. Especificación Técnica y Alcance
- Controlador y servicio `products.controller`, `products.service`.
- Validación de precios (números positivos) y comisiones fijas monetarias.
- Regla de inmutabilidad: los distribuidores solo pueden invocar `GET /api/products`.

## 4. Criterios de Aceptación Técnicos (DoD de la Tarea)
- [x] Endpoints probados y funcionando conforme a la regla de precios inmutables.
- [x] Intento de modificación de precio por un distribuidor rechazado con 403 Forbidden.
- [x] El catálogo devuelve títulos, niveles, precios fijos y comisiones correctamente.

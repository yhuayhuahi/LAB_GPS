# TASK-01-05: Interfaz web móvil (Mobile-First) de inicio de sesión y gestión de sesión

## 1. Descripción Técnica
Diseñar e implementar la vista de Login con enfoque mobile-first optimizada para teléfonos móviles de los vendedores. Incluir formulario táctil, validación visual de errores, consumo del API de login y almacenamiento local seguro del token JWT y rol activo.

## 2. Historia de Usuario Vinculada
- **Historia Padre:** [[HU-01]]
- **Dependencias Técnicas (Bloqueado por):** [[TASK-01-01]] (Scaffolding frontend)
- **Componente de Arquitectura:** Frontend
- **Estimación:** 5 horas-hombre

## 3. Especificación Técnica y Alcance
- Vista responsiva `LoginView` (diseño mobile-first, inputs accesibles).
- Servicio de autenticación frontend (`authService.login()`, `logout()`).
- Manejo de estado de sesión (React Context / Pinia / LocalStorage).
- Redirección automática según rol (Admin -> Dashboard, Distribuidor -> POS de ventas).

## 4. Criterios de Aceptación Técnicos (DoD de la Tarea)
- [x] Interfaz totalmente adaptable a pantallas móviles (360px a 420px de ancho).
- [x] Muestra mensajes claros ante errores de conexión o credenciales incorrectas.
- [x] Persistencia de sesión al recargar la página si el token sigue vigente.
- [x] Cierre de sesión seguro con limpieza de almacenamiento local.

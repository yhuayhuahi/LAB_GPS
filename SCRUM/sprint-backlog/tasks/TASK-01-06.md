# TASK-01-06: Pruebas de integración de autenticación y seguridad RBAC

## 1. Descripción Técnica
Elaborar y ejecutar la suite de pruebas automatizadas y manuales para el flujo de autenticación, verificación de tokens JWT manipulados o expirados, y confirmación del bloqueo de rutas entre roles y sedes.

## 2. Historia de Usuario Vinculada
- **Historia Padre:** [[HU-01]]
- **Componente de Arquitectura:** QA
- **Estimación:** 3 horas-hombre

## 3. Especificación Técnica y Alcance
- Suite de pruebas de integración para endpoints de autenticación.
- Casos de prueba de roles: Administrador vs Distribuidor vs Logística.
- Pruebas de seguridad: inyección SQL básica en login, tokens falsificados.

## 4. Criterios de Aceptación Técnicos (DoD de la Tarea)
- [ ] Casos de prueba documentados con matriz de entrada/salida esperada.
- [ ] Todas las pruebas de integración ejecutadas y en verde en el entorno local.
- [ ] Aislamiento de sedes verificado formalmente sin fugas de información.

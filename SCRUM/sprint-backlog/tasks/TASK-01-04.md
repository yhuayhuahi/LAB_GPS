# TASK-01-04: Middleware de autorización RBAC y aislamiento por sede

## 1. Descripción Técnica
Desarrollar middlewares para verificar el token JWT y comprobar los permisos por rol antes de acceder a rutas protegidas. Implementar la regla de negocio crítica RN-05: aislar las consultas para que los usuarios con rol Distribuidor solo puedan acceder a los recursos vinculados a su `branch_id`.

## 2. Historia de Usuario Vinculada
- **Historia Padre:** [[HU-01]]
- **Dependencias Técnicas (Bloqueado por):** [[TASK-01-03]] (API REST de autenticación)
- **Componente de Arquitectura:** Backend
- **Estimación:** 4 horas-hombre

## 3. Especificación Técnica y Alcance
- Middleware `authenticateToken` para validar firma y expiración de JWT.
- Middleware `requireRole(['ADMIN', ...])` para control de acceso basado en roles.
- Middleware `enforceBranchScope` que inyecta y valida el `branch_id` del usuario en las peticiones.

## 4. Criterios de Aceptación Técnicos (DoD de la Tarea)
- [x] Petición sin token o con token expirado rechazada con 401 Unauthorized.
- [x] Distribuidor intentando acceder a rutas administrativas rechazado con 403 Forbidden.
- [x] Distribuidor intentando consultar datos de otra sucursal bloqueado automáticamente.
- [x] Tests unitarios de middlewares con cobertura > 85% verificados en suite automatizada.

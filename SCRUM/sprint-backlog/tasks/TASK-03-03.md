# TASK-03-03: Interfaz web de gestión del catálogo de libros y comisiones

## 1. Descripción Técnica
Desarrollar la pantalla de administración del catálogo de libros dentro del panel del Administrador: tabla interactiva con título, nivel (Básico/Intermedio/Avanzado/Médico), precio de venta (S/), comisión fija (S/) y modal de registro/edición.

## 2. Historia de Usuario Vinculada
- **Historia Padre:** [[HU-03]]
- **Dependencias Técnicas (Bloqueado por):** [[TASK-03-01]] (DDL products), [[TASK-01-05]] (Frontend login)
- **Componente de Arquitectura:** Frontend
- **Estimación:** 5 horas-hombre

## 3. Especificación Técnica y Alcance
- Vista `ProductsCatalogView` con filtros por nivel y categoría.
- Formulario modal `ProductFormModal` con cálculo visual de margen neto (Precio - Comisión).
- Formateo estándar de moneda peruana (S/ 0.00).

## 4. Criterios de Aceptación Técnicos (DoD de la Tarea)
- [ ] El Administrador puede registrar nuevas publicaciones y ajustar tarifas y comisiones.
- [ ] El formulario valida que el precio de venta sea coherente y mayor a la comisión.
- [ ] Interfaz responsiva con renderizado dinámico del catálogo.

# TASK-07-02: Endpoints REST de salidas especiales con validación de justificación (RN-07)

## 1. Descripción Técnica
Desarrollar endpoints `POST /api/v1/inventory/non-commercial-exits` y `GET /api/v1/inventory/non-commercial-exits`.
- Validar mediante Zod que la justificación no esté vacía y posea mínimo 5 caracteres (RN-07).
- Descontar atómicamente del inventario correspondiente (`central_stock` o `branch_stock`).
- Prohibir bajas si las existencias son insuficientes (400 Bad Request).
- Restringir la creación a roles autorizados (`ADMIN` y `LOGISTICS`).

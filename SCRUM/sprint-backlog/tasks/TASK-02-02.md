# TASK-02-02: Endpoints REST para gestión de distribuidoras y personal

## 1. Descripción Técnica
Implementar endpoints protegidos para Administrador: `GET /api/branches` (listar sedes), `POST /api/branches` (crear sede), `PUT /api/branches/:id` (actualizar datos/estado) y `GET /api/branches/:id/users` (listar vendedores asignados).

## 2. Historia de Usuario Vinculada
- **Historia Padre:** [[HU-02]]
- **Componente de Arquitectura:** Backend
- **Estimación:** 4 horas-hombre

## 3. Especificación Técnica y Alcance
- Controlador y servicio `branches.controller`, `branches.service`.
- Validaciones de entrada (nombre obligatorio, formato de teléfono y correo).
- Restricción de acceso exclusiva para el rol `ADMIN`.

## 4. Criterios de Aceptación Técnicos (DoD de la Tarea)
- [ ] Endpoints CRUD probados y respondiendo códigos HTTP estándar (200, 201, 400, 404).
- [ ] Validación contra nombres o correos de sedes duplicadas.
- [ ] Acceso bloqueado con 403 Forbidden para usuarios que no sean Administradores.

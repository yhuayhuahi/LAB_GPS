# TASK-01-03: Implementación de API REST de autenticación y tokens JWT

## 1. Descripción Técnica
Construir los endpoints de autenticación: `POST /api/auth/login` y `GET /api/auth/me`. Implementar validación de credenciales con hashing seguro mediante bcrypt y emisión de JSON Web Tokens (JWT) que contengan `user_id`, `role` y `branch_id`.

## 2. Historia de Usuario Vinculada
- **Historia Padre:** [[HU-01]]
- **Componente de Arquitectura:** Backend
- **Estimación:** 6 horas-hombre

## 3. Especificación Técnica y Alcance
- Controlador y servicio de autenticación (`auth.controller`, `auth.service`).
- Validación de datos de entrada con esquema (email válido, contraseña no vacía).
- Comparación de contraseña con hash bcrypt (mínimo 10 rondas de salt).
- Emisión de token JWT con tiempo de expiración configurable.

## 4. Criterios de Aceptación Técnicos (DoD de la Tarea)
- [ ] Endpoint de login responde 200 OK con token válido ante credenciales correctas.
- [ ] Endpoint responde 401 Unauthorized ante contraseña o usuario inválido.
- [ ] Las contraseñas se almacenan únicamente como hashes bcrypt.
- [ ] Pruebas de endpoints verificadas mediante colección Postman/cURL.

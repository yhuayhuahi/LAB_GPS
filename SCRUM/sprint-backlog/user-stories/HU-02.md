# HU-02: Gestión del padrón de locales distribuidores

## 1. Descripción de la Historia
> **Como** Administrador,  
> **quiero** registrar y administrar las distribuidoras aliadas (nombre, dirección, teléfono, correo y encargados),  
> **para** mantener actualizado el padrón de puntos de venta y habilitar la asignación de usuarios y stock.

## 2. Contexto de Negocio
Según la entrevista (Preg. 73, 98), QSY trabaja con 3 distribuidoras céntricas en Arequipa y planea expandirse; el Administrador es el único responsable de dar de alta nuevas sedes y vincular a sus vendedores.

## 3. Criterios de Aceptación (Gherkin)
- **Escenario 1:** Alta de nueva distribuidora.  
  *DADO QUE* el Administrador ingresa los datos de un nuevo local aliado (nombre, dirección, responsable),  
  *CUANDO* presiona 'Guardar Sucursal',  
  *ENTONCES* el sistema crea la sede, genera su identificador unívoco y la habilita para recibir transferencias de libros.
- **Escenario 2:** Asignación de vendedores a sede.  
  *DADO QUE* se da de alta un usuario vendedor,  
  *CUANDO* el Administrador selecciona su distribuidora correspondiente,  
  *ENTONCES* el usuario queda vinculado a dicha sede para todas sus operaciones transaccionales.

## 4. Reglas de Negocio Asociadas
- **RN-05 (Aislamiento de sedes):** Toda operación transaccional requiere una sede activa vinculada.

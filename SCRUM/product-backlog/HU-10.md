# HU-10: Operación offline y sincronización diferida por datos móviles

## 1. Descripción de la Historia
> **Como** Distribuidor,  
> **quiero** registrar ventas de forma local en el navegador del celular cuando no haya internet y sincronizarlas cuando active mis datos móviles,  
> **para** seguir atendiendo sin interrupciones en locales que no disponen de conexión fija o tienen señal inestable.

## 2. Contexto de Negocio
Aclaración de entrevista: 2 de las 3 sedes no tienen internet contratado. Los vendedores usan datos móviles personales puntuales. El sistema debe guardar las ventas localmente (IndexedDB) y subirlas por lotes cuando se conecten.

## 3. Criterios de Aceptación (Gherkin)
- **Escenario 1:** Venta sin conexión a internet.  
  *DADO QUE* el dispositivo no tiene datos móviles activos,  
  *CUANDO* el vendedor confirma una venta,  
  *ENTONCES* el sistema guarda la transacción en el almacenamiento local del celular, descuenta el stock visual y muestra estado 'Pendiente de sincronizar'.
- **Escenario 2:** Sincronización al activar datos.  
  *DADO QUE* existen transacciones guardadas localmente y el vendedor activa su conexión,  
  *CUANDO* pulsa 'Sincronizar Ventas' (o el sistema detecta red),  
  *ENTONCES* las ventas se transmiten al servidor central, se actualizan saldos globales y se marca 'Sincronizado'.

## 4. Reglas de Negocio Asociadas
- **RN-04 (Descuento inmediato):** El stock local se reserva en el dispositivo para no vender dos veces el mismo ejemplar sin red.

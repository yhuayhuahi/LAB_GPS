# HU-09: Validación estricta de stock previo a la venta

## 1. Descripción de la Historia
> **Como** Distribuidor,  
> **quiero** que el sistema valide el stock asignado antes de confirmar,  
> **para** evitar sobreventas accidentales.

## 2. Contexto de Negocio
Según la entrevista (Preg. 3, 22, 86), está terminantemente prohibido vender libros si no existe stock disponible asignado al local. El sistema debe bloquear la venta ante quiebre de stock.

## 3. Criterios de Aceptación (Gherkin)
- **Escenario 1:** Stock disponible conforme.  
    *DADO QUE* la cantidad solicitada es menor o igual al saldo local,  
    *CUANDO* el vendedor selecciona el libro,  
    *ENTONCES* el sistema habilita el botón de confirmación.
  - **Escenario 2:** Intento de venta con stock cero.  
    *DADO QUE* el stock local de un libro es cero,  
    *CUANDO* el vendedor intenta seleccionarlo para venta,  
    *ENTONCES* el sistema inhabilita la opción, muestra mensaje de "Agotado en este local" y bloquea la operación.

## 4. Reglas de Negocio Asociadas
- **RN-01 (Prohibición de sobreventa):** No se permite registrar una venta con stock igual a cero o insuficiente.
- **RN-02 (Obligatoriedad de comprobante):** Toda venta efectuada debe tener obligatoriamente un comprobante asociado.
- **RN-03 (Precios fijos):** El precio de venta al público es fijo por producto; no se admiten descuentos discrecionales.
- **RN-04 (Descuento inmediato de stock):** Las unidades se descuentan del inventario del local en el instante de confirmar la venta.

# HU-15: Movimientos especiales de inventario

## 1. Descripción de la Historia
> **Como** Logística,  
> **quiero** registrar salidas no comerciales (docentes, sorteos, cortesías, mermas o pérdidas) con justificación obligatoria,  
> **para** justificar las bajas de stock.

## 2. Contexto de Negocio
Según la entrevista (Preg. 63-66), ocurren salidas no comerciales frecuentes (docentes, promociones, sorteos, cortesías, mermas) que actualmente no se registran. Se exige motivo obligatorio y usuario autorizador.

## 3. Criterios de Aceptación (Gherkin)
- **Escenario 1:** Registro con justificación completa.  
    *DADO QUE* se retira un libro sin generar venta directa,  
    *CUANDO* Logística selecciona el tipo de salida, ingresa el motivo formal detallado y confirma,  
    *ENTONCES* el sistema descuenta la unidad del kardex registrando fecha, hora, motivo y usuario autorizador.
  - **Escenario 2:** Rechazo por motivo ausente.  
    *DADO QUE* el campo "Motivo / Justificación" se encuentra vacío,  
    *CUANDO* se intenta procesar la salida,  
    *ENTONCES* el sistema bloquea la operación y exige ingresar el motivo.

## 4. Reglas de Negocio Asociadas
- **RN-01 (Prohibición de sobreventa):** El inventario central valida existencias antes de todo egreso.
- **RN-07 (Justificación obligatoria):** Toda salida que no genere ganancia directa exige motivo formal obligatorio y usuario autorizador.

# HU-07: Registro de salidas no comerciales y mermas justificadas

## 1. Descripción de la Historia
> **Como** Encargado de Logística,  
> **quiero** registrar salidas de libros sin venta (muestras a docentes, cortesías, promociones, sorteos o ejemplares dañados) con justificación obligatoria,  
> **para** evitar mermas encubiertas y mantener cuadrado el kardex de almacén.

## 2. Contexto de Negocio
Según la entrevista (Preg. 64-66, 153-160), todas estas salidas ocurren en la realidad pero no se documentaban. Se acordó exigir motivo obligatorio y autorización exclusiva de Logística.

## 3. Criterios de Aceptación (Gherkin)
- **Escenario 1:** Registro de salida con motivo.  
  *DADO QUE* se entrega un libro para muestra docente o sorteo,  
  *CUANDO* Logística selecciona el tipo de salida, ingresa el motivo detallado y guarda,  
  *ENTONCES* el sistema descuenta la unidad registrando fecha, hora, usuario y justificación.
- **Escenario 2:** Bloqueo por falta de justificación.  
  *DADO QUE* se intenta registrar una merma o salida sin escribir el motivo,  
  *CUANDO* se pulsa confirmar,  
  *ENTONCES* el sistema bloquea la acción y exige el texto de justificación.

## 4. Reglas de Negocio Asociadas
- **RN-07 (Justificación obligatoria):** Toda baja o salida no comercial requiere motivo explícito y trazable.

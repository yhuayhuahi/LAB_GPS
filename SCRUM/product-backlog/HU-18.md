# HU-18: Búsqueda histórica de compras por DNI del estudiante para reclamos

## 1. Descripción de la Historia
> **Como** Administrador,  
> **quiero** buscar el historial de compras de un estudiante ingresando su número de DNI,  
> **para** verificar rápidamente la autenticidad de una compra cuando un estudiante acuda con un libro defectuoso sin comprobante físico.

## 2. Contexto de Negocio
Aclaración de entrevista: Se descartó el código de libro (que era solo para la web). La comprobación real de reclamos se hace buscando el DNI del alumno para ver fecha de compra, sede y libro entregado (conservado por 2 años según Preg. 41-45, 125).

## 3. Criterios de Aceptación (Gherkin)
- **Escenario 1:** Estudiante con compra registrada.  
  *DADO QUE* un estudiante presenta un libro con fallas de imprenta y no tiene boleta,  
  *CUANDO* el Administrador o Soporte ingresa su DNI en el buscador,  
  *ENTONCES* el sistema muestra la fecha de compra, la sucursal donde adquirió el libro, el título y el comprobante asociado.
- **Escenario 2:** DNI sin registros.  
  *DADO QUE* se ingresa un DNI que no existe en la base de datos de ventas,  
  *CUANDO* se ejecuta la búsqueda,  
  *ENTONCES* el sistema informa 'No se registran compras asociadas a este DNI'.

## 4. Reglas de Negocio Asociadas
- **RN-08 (Auditoría e Inmutabilidad):** El historial de ventas se conserva íntegro durante al menos 2 años.
